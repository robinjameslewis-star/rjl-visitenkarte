As a bookkeeper, I sit between media. An invoice arrives by email, I print it out, file it, later dig it out again and type the data into the accounting system. From data record to paper and back.

This media break is so routine that it barely registers. Yet it causes a large share of the manual work in accounting – and many of the errors.

The GoBD amendment of 14 July 2025 took an important step: with an e-invoice, the structured data record *is* the invoice, not the image. Dual archiving (XML plus a visual copy) is no longer required (GoBD para. 76). For hybrid formats such as ZUGFeRD, archiving the XML file is generally sufficient if it contains all the tax-relevant information. The GoBD apply immediately, with no transition period (para. 185).

This means: the last excuse for printing data is gone.

An example: a client sends their monthly rent receipt list as a PDF. I print it, put it in the folder, later enter the payments from the bank statement and the list into accounts receivable. The data in the list never reaches my system as a data record – only as paper. Yet the list is digital. The printout is a media break I created myself.

Those who adapt their processes now save more than just printing and filing. Tax auditors can access the data records directly instead of reviewing document images. And transaction entry becomes faster because no more data has to be transferred from paper into a system.

The 2025 GoBD have set the course. Now it is the processes' turn.
