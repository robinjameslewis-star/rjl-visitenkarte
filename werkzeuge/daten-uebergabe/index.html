Daten mitnehmen nach smartformular.ai

SmartFormular E-Rechnung Start (bisher E-Rechnung lite) und SmartFormular Buchhaltung Start (bisher FiBu lite) sind auf smartformular.ai umgezogen. Haben Sie die Werkzeuge hier benutzt, liegen Ihre Einstellungen und Ihre Anmeldung im Speicher dieses Browsers unter robin.vision.

So geht es: Klicken Sie auf „Meine Daten mitnehmen“. Es öffnet sich smartformular.ai; dort wählen Sie „Daten empfangen“. Die Daten gehen direkt von Fenster zu Fenster in Ihrem Browser, nicht über einen Server und nicht in eine Adresse. Ohne Klick passiert nichts.
