BR-CL-16

Der Code der Zahlungsart (BT-81) ist nicht zulässig

Prüfregel der EN 16931 (CEN, Prüfregeln 1.3.16) · Stufe: Fehler

Was die Meldung bedeutet

Der Code der Zahlungsart (BT-81) ist nicht zulässig.

Was der Rechnungssteller ändern muss

Einen zulässigen Code verwenden, zum Beispiel 58 für SEPA-Überweisung.

Betroffene Felder

  • BT-81 Code der Zahlungsart
