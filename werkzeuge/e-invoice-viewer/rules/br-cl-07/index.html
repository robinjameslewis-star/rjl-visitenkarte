BR-CL-07

The scheme of the object identifier (BT-18) is not allowed

Validation rule of EN 16931 (CEN, rule set 1.3.16) · Level: Error

What the message means

The scheme of the object identifier (BT-18) is not allowed.

What the issuer needs to change

Use a valid code.

Fields concerned

  • BT-18 invoiced object identifier

Original rule text

Object identifier identification scheme identifier MUST be coded using a restriction of UNTDID 1153.

Source: CEN/TC 434, EN 16931 validation rules 1.3.16, European Union Public Licence 1.2
